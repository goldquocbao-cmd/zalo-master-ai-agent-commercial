## 📌 Giới Thiệu
**Zalo Master AI Agent** là giải pháp "Nhân Sự Số" toàn diện chạy 24/7 trên Zalo (Hỗ trợ Zalo Cá Nhân, Zalo OA & Zalo Nhóm) tích hợp trọn bộ **12 Nhóm Năng Lực** tự động hóa.

### 🌟 12 Nhóm Năng Lực Nổi Bật:
1. **💬 Chat Rich Text**: Giọng điệu người thật, xưng tên khách (*"Dạ vâng Chị Minh ạ"*), định dạng chữ màu Zalo.
2. **📥 Tải Media Không Logo**: Tải video TikTok, YouTube, FB, IG qua Cobalt Engine.
3. **📝 Văn Phòng Số**: Soạn thảo văn bản hành chính chuẩn **Nghị định 30/2020/NĐ-CP**.
4. **🛡️ Quản Trị Nhóm**: Anti-Spam tự động phát hiện tin rác cờ bạc & kick thành viên vi phạm.
5. **⚙️ Tiếp Quản Thủ Công**: Lệnh `/pause` & `/resume` trực tiếp từ ứng dụng Zalo trên điện thoại.
6. **🧠 Second Brain**: Tự động đồng bộ ghi chú khách hàng với Notion.

## 🚀 Hướng Dẫn Triển Khai Lên Vercel Cloud (0% RAM Local)

### 1. Đẩy Mã Nguồn Lên GitHub Của Bạn
```bash
git init
git add .
git commit -m "feat: Initial Zalo Master AI Agent Commercial Codebase"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/zalo-master-ai-agent-commercial.git
git push -u origin main
```

### 2. Triển Khai Lên Vercel (1-Click Deploy)
1. Đăng nhập [Vercel.com](https://vercel.com).
2. Bấm **Add New -> Project**.
3. Chọn Repository `zalo-master-ai-agent-commercial` từ GitHub của bạn.
4. Bấm **Deploy**. Nhận ngay trang Web App thương mại chạy 24/7 toàn cầu!
